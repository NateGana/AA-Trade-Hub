AA TRADEHUB (fan-made demo)

How to open: unzip, then double-click index.html in a modern browser. No install needed.
Internet is only used for the Chart.js chart on the Progress page.

All data is saved in your browser (localStorage). Accounts are demo only and not secure.
Reset everything in Settings > Reset all demo data.
Unit values and listings are sample data, not verified market values.
